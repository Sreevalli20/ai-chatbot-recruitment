# 🤖 AI-Powered Recruitment Chatbot

This is a smart AI chatbot for automating candidate screening, resume analysis, and interview evaluations. Built with Python & Streamlit.

---

## 💡 Features

- 📄 Resume Parsing & Keyword Extraction
- 🎤 Voice-based Interview Q&A
- 📬 Email Results to Candidates
- 🤖 Auto-scoring & Shortlisting
- 📊 Admin Dashboard with Filters
- 🎨 Stylish UI & UX (Bonus Touch)

---

## 🚀 How to Run

### 1. Clone/Extract Project
Place the project folder on your E: drive or any location.
